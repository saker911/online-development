# قواعد النصوص داخل الواجهة

## استعادة الحساب

- يطلب النموذج من المستخدم **اسم المستخدم أو البريد الإلكتروني** فقط.
- لا تشرح الواجهة آلية إنشاء الرموز أو التحقق أو المطابقة أو الإرسال.
- تكون رسالة النتيجة مختصرة وعامة، ولا تؤكد وجود الحساب أو عدمه.
- تبقى التفاصيل الأمنية والتقنية داخل الخدمات والسجلات، ولا تظهر للمستخدم.
