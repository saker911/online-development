# المرحلة صفر: خط الأساس لمنصة تصاريح

تاريخ التنفيذ: 8 أغسطس 2026

## القرار التنفيذي

اكتملت المرحلة صفر. النسخة الحالية صالحة لتجربة تشغيل تجارية محدودة مع جهة أو جهتين، وليست جاهزة بعد لإطلاق عام ذاتي الدفع. تم تثبيت خط أساس قابل للقياس قبل بدء تطوير مركز الدخول والخدمة الذاتية والطابور.

## خط الأساس التقني

- التطبيق: ASP.NET Core MVC على .NET 8.
- قاعدة الإنتاج: PostgreSQL 16 داخل شبكة Docker داخلية.
- النشر: GitHub إلى خادم Hostinger، ثم Docker Compose وCaddy.
- النطاق: `https://tasareehapp.com`.
- عزل الجهات: هوية جهة إلزامية على الحسابات والبيانات التشغيلية.
- الدخول العام: Google أو بريد مؤكد بحسب إعدادات الإنتاج.
- الواجهات التشغيلية: التصاريح، الزيارات، المستخدمون، البوابات، QR، شاشة المسح، العرض، التقارير، والمراقبة.

## نتائج الاختبارات

- اختبارات المنطق والخدمات: **53 من 53 ناجحة**.
- اختبارات المتصفح Chromium: **54 من 54 ناجحة**.
- شملت اختبارات المتصفح العزل والصلاحيات والتصاريح والزيارات والبوابة والتقارير والجداول والجوال والواجهة العامة.
- اختبار الواجهة الجديدة أثبت تبدل النمط، اكتمال تحميل صورة المنتج، وعدم وجود تمرير أفقي على عرض 390 بكسل.
- البناء المحلي: ناجح دون أخطاء أو تحذيرات.

## حالة الإنتاج وقت المراجعة

- الإصدار المنشور قبل تغييرات الواجهة الحالية: `5b437a7`.
- خدمة التطبيق: تعمل.
- PostgreSQL: تعمل وحالتها `healthy`.
- Caddy وHTTPS: يعملان.
- `/healthz`: أعاد `200 OK`.
- HSTS وCSP و`X-Content-Type-Options` و`X-Frame-Options: DENY` مفعلة.
- اتصال SSH كان متقطعاً في إحدى المحاولات ثم نجح؛ يلزم مراقبة مستقلة بدلاً من الاعتماد على الفحص اليدوي.

## ما تم تثبيته في هذه المرحلة

1. خط أساس اختبارات كامل يمكن مقارنة أي مرحلة لاحقة به.
2. جرد واضح لبيانات الاختبار الموجودة في الإنتاج.
3. تأكيد بنية الاستضافة وقاعدة البيانات والعزل والترويسات الأمنية.
4. واجهة رئيسية تعرض المنتج الحقيقي بصرياً في النهاري والليلي والجوال.
5. ترتيب المراحل التالية: مركز الدخول أولاً، ثم الخدمة الذاتية والطابور، ثم تطبيق الجوال.

## موانع الإطلاق العام

1. ربط دفع فعلي واختبار Webhook وفشل السداد والاسترداد والفاتورة.
2. إدخال الهوية القانونية وبيانات الدعم ومراجعة السياسات قانونياً.
3. نسخة احتياطية مشفرة خارج الخادم وتجربة استعادة موثقة.
4. مراقبة توفر وأخطاء وقرص وقاعدة بيانات مع تنبيه مستقل.
5. مصادقة متعددة العوامل لمالك النظام ومديري الجهات.
6. اختبار Google من التسجيل حتى إنشاء الجهة بحساب إطلاق مخصص.
7. اختبار كاميرا Android وiPhone فعلياً في موقع بوابة.
8. توحيد تخزين التواريخ إلى UTC وعرضها بتوقيت الجهة.
