# جدول تنفيذ نسخة الأون لاين

تاريخ بدء التنفيذ: 16 يونيو 2026

## الهدف

تحويل النسخة المعزولة الحالية إلى منتج أون لاين قابل للتشغيل لعدة جهات، مع عزل بيانات كل جهة، قاعدة PostgreSQL، إعداد إنتاجي آمن، وخطط اشتراك واضحة. تبقى النسخة الحكومية المحلية مستقلة ولا تتأثر بهذه الأعمال.

## قرار العزل لأول العملاء

لأول خمس جهات، يستخدم نشر مستقل منطقيًا لكل جهة مع قاعدة PostgreSQL مستقلة. هذا أبسط في النسخ الاحتياطي والاستعادة، ويقلل أثر أي خطأ عزل أثناء مرحلة المنتج الأولى. بعد استقرار المنتج يمكن تقييم نموذج متعدد المستأجرين بقاعدة مشتركة.

## ضوابط المرحلة الأولى

- SQLite يبقى مزود التطوير المحلي الافتراضي.
- PostgreSQL يستخدم في الأون لاين والإنتاج.
- كلمة مرور PostgreSQL تمرر بمتغير بيئة أو مخزن أسرار ولا تكتب في ملفات المشروع.
- ترقيات PostgreSQL تتم عبر EF Core Migrations.
- لا يتم نقل بيانات النسخة الحكومية المحلية تلقائيًا إلى نسخة الأون لاين.
